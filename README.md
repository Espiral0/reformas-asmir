# IMR Reformas

Web de una sola página para una empresa de reformas, hecha con HTML y Tailwind (por CDN).

- `index.html`: la web (diseño de Stitch)
- `plantilla-antigua.html`: plantilla anterior, ya no se usa
- `DESIGN.md`: guía de diseño

Para verla en local, abre `index.html` en el navegador (necesita internet para las fuentes y Tailwind).
